# Contribuindo com a Shine

A Shine continua como projeto de portfólio após o encerramento comercial. Sugestões são bem-vindas, sem prazo garantido de resposta.

1. Descreva o problema antes de propor mudanças extensas.
2. Crie uma branch e mantenha a alteração focada.
3. Execute os comandos de validação do README e informe os resultados no pull request.
4. Atualize a documentação quando o comportamento mudar.
5. Use somente dados fictícios nos exemplos e testes.

Inclua contexto, resultado e validação no pull request. Mudanças visuais devem incluir capturas em desktop e mobile. Não envie credenciais, dados de clientes ou dumps.
