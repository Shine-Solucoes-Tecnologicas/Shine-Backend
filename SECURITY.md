# Segurança

Este projeto é mantido para portfólio e não oferece suporte para produção.

Não publique credenciais, tokens ou dados pessoais em issues ou pull requests. Para vulnerabilidades, use a opção privada “Report a vulnerability” na aba Security do GitHub, se disponível. Caso não esteja habilitada, solicite um canal privado sem publicar detalhes de exploração ou dados sensíveis.

Os exemplos de configuração local não devem ser reutilizados em ambientes públicos. Segredos reais devem permanecer fora do Git e ser substituídos caso tenham sido expostos.
